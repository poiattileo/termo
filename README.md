# Gerador de Termo de Retirada

> Gere o Termo de Retirada de Equipamento de forma rápida, fiel ao modelo oficial e pronta para impressão.

## Sobre

O **Gerador de Termo de Retirada** facilita o preenchimento do documento oficial de retirada de equipamentos. Basta informar a escola e os itens — o sistema apresenta uma pré-visualização em tamanho A4 idêntica ao modelo original, pronta para imprimir ou salvar em PDF.

Funciona 100% no navegador, sem envio de dados para servidor.

## Para que serve

- **Agilizar a emissão** — Busca inteligente entre as escolas vinculadas com seleção rápida.
- **Padronizar o documento** — Layout fiel ao modelo, com brasão, cabeçalho e campos de assinatura.
- **Personalizar conteúdo** — Adição e remoção de linhas de equipamentos com atalhos práticos.
- **Imprimir com qualidade** — Visualização ao vivo e geração em A4 para impressão ou PDF.

## Destaques

- Pré-visualização ao vivo com zoom
- Lista pré-preenchida editável e expansível
- Campos em branco para preenchimento à caneta quando necessário
- Sem dependências — arquivo único, leve e offline após carregar
- Histórico opcional de impressões com retenção configurável

## Tecnologias

HTML · CSS · JavaScript puro
